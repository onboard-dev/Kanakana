KanaKana 1.0.4 です。縮小表示を浮かせて動かせるようにし、片手モードを左右の段階で動かせるようにした更新版です。

## 主な変更
- **縮小表示**: ◾ を押すたびに、通常 → 80% → 60% → 50% → 通常と縮小します(40%・30% はなくしました)。縮小中、キーボードはアプリの上に浮かび、空いた部分は透明で、そこへのタップは後ろのアプリに届きます。
- **フローティングモード**: ◾ を**長押し**すると、キーボードが浮かび、上部の ━ をドラッグして、好きな位置に動かせます。位置は保存されます。もう一度長押しで解除します。
- **片手モード**: ボタンを押すたびに、全幅 → 左寄せ 80% → 70% → 60% → 右寄せ 60% → 70% → 80% → 右 70% → 60% → 左 60% → 70% → 80% → 全幅の順に動きます。ボタンの**長押し**で、どの位置からでも全幅に戻ります。縮小しない片手モードでも、空いた側は透明で、タップは後ろのアプリに届きます。
- **URL・メールアドレス欄・ターミナル**: 自動では英数入力に切り替えません。選んだ入力方式のまま、自分で切り替えます。ターミナル(`TYPE_NULL`)でも、ハードウェアキーボードのかな入力と英数入力の切り替えが効きます。パスワード欄は、これまでどおり英数入力です。
- **フリックガイド**: ガイドの文字色を、「テーマの色(初期値)」「白」「黒」から選べます。練習モードの表示を、「▼(70%の大きさ)」か「フルサイズの四角」から選べます。設定 → 入力方式の一番下です。
- 1.0.3 までの変更も、引き続き含みます。

## 動作を確認した環境
- Android エミュレータ(Medium_Tablet、x86_64)で、縮小表示の透過とフローティングの移動・解除、片手モードの段階移動と長押し、URL 欄(Chrome のアドレスバー)での日本語入力、フリックガイドの文字色と四角の表示を確認しました。
- ビルド、lint、単体テストも通っています。
- ほかの確認環境は、READMEの「動作確認した環境」を参照してください。

## 実機で未確認の項目
- 実機(Galaxy S23 など)での、フローティングモードの移動と解除、片手モードの段階移動(エミュレータでの確認のみ)
- エミュレータは、「半角/全角」「無変換」「変換」「カタカナひらがな」のキーを通さないため、これらのキーの動作は、今回のエミュレータでは確認していません(1.0.1 のリリースノートを参照)
- ターミナルアプリでの、ハードウェアキーボードのかな入力と英数入力の切り替え
- 幅の狭い端末で、ツールが 6 個並ぶ表示
- Google ドライブでの書き出しと復元
- OpenRouter への接続
- 追加システム辞書を「すべて」にしたときの変換速度への影響
- 他の Android のバージョン、3ボタン / ジェスチャーナビ
- N100 などの x86_64 の Android(x86_64 版)での動作

## 配布する APK
配布する APK は **debug 署名のテスト用**で、アプリ ID は `jp.kanakana.ime.debug` です。正式な署名鍵は用意していません。1.0.0 から 1.0.3 と同じ署名なので、上書きで更新できます。

### ファイルの選び方
| ファイル | 対象 |
|---|---|
| `KanaKana-1.0.4-arm64-debug.apk` | 一般的なスマホ・タブレット(arm64)。AI 変換(Karukan・zenzai-plus)も使えます |
| `KanaKana-1.0.4-x86_64-debug.apk` | Intel / AMD の CPU で動く Android(N100 などのミニ PC、Android-x86 系、エミュレータ)。**AI 変換は使えません**(Mozc の変換のみ)。この組み合わせでの動作は、未確認です |
