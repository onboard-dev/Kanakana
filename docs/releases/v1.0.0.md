KanaKana 1.0.0 です。Komorebi IME(0.3.0-rc.68-dev)のフォークとして、物理 JIS キーボードのかな入力を中心に、入力・定型文・AI・バックアップを拡張した最初の公開版です。

## 主な変更
- **JIS かな入力**: Bluetooth などの JIS キーボードで、キーの印字どおりにかなを入力できます。物理キーボード接続中は、候補バーだけを表示します。
- **変換エンジン**: 「自動(おすすめ)」と「Mozcのみ」の2択に整理しました。「自動」では zenzai-plus(優先)と Karukan を個別に選べます。「Mozcのみ」では zenzai-plus も止まります。
- **定型文**: パスワード付きの暗号化ファイルでインポート/エクスポートできます。メニューボタンの長押しで、最近使った5件を挿入できます。差し込み項目 `{{名前}}` で挿入できなかった不具合と、英字が大文字で表示される問題を修正しました。
- **AI 校正**: 接続先を、端末内・OpenRouter・Ollama から選べます。外部を選んだときだけ、文章を送信します。
- **バックアップ**: Google ドライブへの書き出し/読み込みを追加しました。ファイル名は `kanakana-settings-yyMMdd.kkbak` です。
- **見た目**: 単色テーマ10種、新しいアプリアイコン、ツールメニューの高さ、定型文と「画像から文字」のアイコンを変更しました。
- **名称**: アプリ名を KanaKana、アプリ ID を `jp.kanakana.ime` に変更しました。更新確認は、このリポジトリの Release を見ます。

変更点の全体は [README](../../README.md) を参照してください。

## 実機で未確認の項目
- Google ドライブでの書き出しと復元
- 新しいアイコンの見え方(ホーム画面、ツール列)
- 変換エンジンの新しい画面と、「Mozcのみ」で AI の候補が出ないこと
- 追加システム辞書を「すべて」にしたときの変換速度への影響
- OpenRouter への接続
- Android 24 / 29 / 34 / 35 の端末、3ボタン / ジェスチャーナビ

動作確認は、Galaxy S23(ドコモ版、Android 16)と Bluetooth キーボード1機種です。

## 配布する APK
配布する APK は **debug 署名のテスト用**で、アプリ ID は `jp.kanakana.ime.debug` です。正式な署名鍵は用意していません。音声入力(別アプリ `me.zssu.ime.voice`)との連携は動作しません。

### ファイルの選び方
| ファイル | 対象 |
|---|---|
| `KanaKana-1.0.0-arm64-debug.apk` | 一般的なスマホ・タブレット(arm64)。AI 変換(Karukan・zenzai-plus)も使えます |
| `KanaKana-1.0.0-x86_64-debug.apk` | Intel / AMD の CPU で動く Android(N100 などのミニ PC、Android-x86 系、エミュレータ)。**AI 変換は使えません**(Mozc の変換のみ)。この組み合わせでの動作は、未確認です |
