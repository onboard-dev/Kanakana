KanaKana 1.0.3 です。フリック入力を練習しやすくする機能と、画面全体を縮小して表示する機能を追加した更新版です。

## 主な変更
- **フリック練習モード**: スワイプ(フリック)入力では、指に隠れて、下フリックの文字が見えません。フリックのキーを押したとき、下フリックの文字を、斜め左下(または右下)に、70%の大きさの ▼ で表示します。その ▼ の方向(斜め下)にフリックしても、下フリックの文字が入ります。設定 → 入力方式の一番下で、「表示しない」「左下」「右下」から選びます(初期値は表示しない)。
- **フリックの4方向の案内を不透明に**: 案内の背景が透けて、下のキーの文字と重なっていたのを、くっきり見えるようにしました。
- **縮小表示**: ツールバーの ◾(✨の右隣)を押すたびに、メニューボタン、ツールバー、候補バー、キーのすべてが、通常 → 60% → 50% → 40% → 30% → 通常と縮小します。縮小して空いた部分は透明で、そこへのタップは後ろのアプリに届きます。ツールバーに並べられるツールを、5 個から 6 個にしました。
- **AI 文章校正モデル画面**: 「クラウド(OpenRouter)またはローカル(Ollama)」のカードを、Qwen などのモデルのカードの上に置き、同じラジオボタンの組にしました。カード内の「設定」ボタンで、接続先の設定画面を開きます。
- 1.0.2 までに入れた、校正モデル画面の変更と、キーボード配列の判定ボタンも、引き続き含みます。

## 動作を確認した環境
- Galaxy S23(Android 16、1.0.2 からの上書き更新)で、フリック練習モード(左下・右下、斜めのフリック)、案内の不透明化、縮小表示(5段階)、校正モデル画面のカードを確認しました。
- ビルド、lint、単体テストも通っています。
- ほかの確認環境は、READMEの「動作確認した環境」を参照してください。

## 実機で未確認の項目
- 縮小表示のとき、機種によっては、空いた部分へのタップが、後ろのアプリに届かない可能性があります(Galaxy S23 での確認のみ)。
- 幅の狭い端末で、ツールが 6 個並ぶ表示
- Google ドライブでの書き出しと復元
- 変換エンジンの新しい画面と、「Mozcのみ」で AI の候補が出ないこと
- 追加システム辞書を「すべて」にしたときの変換速度への影響
- OpenRouter への接続
- 他の Android のバージョン、3ボタン / ジェスチャーナビ
- N100 などの x86_64 の Android(x86_64 版)での動作

## 配布する APK
配布する APK は **debug 署名のテスト用**で、アプリ ID は `jp.kanakana.ime.debug` です。正式な署名鍵は用意していません。1.0.0 から 1.0.2 と同じ署名なので、上書きで更新できます。

### ファイルの選び方
| ファイル | 対象 |
|---|---|
| `KanaKana-1.0.3-arm64-debug.apk` | 一般的なスマホ・タブレット(arm64)。AI 変換(Karukan・zenzai-plus)も使えます |
| `KanaKana-1.0.3-x86_64-debug.apk` | Intel / AMD の CPU で動く Android(N100 などのミニ PC、Android-x86 系、エミュレータ)。**AI 変換は使えません**(Mozc の変換のみ)。この組み合わせでの動作は、未確認です |
