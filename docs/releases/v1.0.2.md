KanaKana 1.0.2 です。入力方式の「認識されているハードウェアキーボード」に、配列の判定ボタンを追加した更新版です。

## 主な変更
- **「いますぐキーボード配列を判定」ボタン**: 設定 → 入力方式の「認識されているハードウェアキーボード」のカードに追加しました。キーを押したあと、このボタンで、JIS 配列かどうかの判定結果をすぐに確認できます。JIS 配列のキーが未検出のときは、¥・ろ・無変換・変換のどれかを押してから、もう一度押すよう案内します。これまでは、入力欄に打ったキーが、この画面に反映されない場合がありました。

## 動作を確認した環境
- Galaxy S23(Android 16、1.0.1 からの上書き更新)で、「いますぐキーボード配列を判定」ボタンが表示され、判定できることを確認しました。
- ビルド、lint、単体テストも通っています。
- 1.0.1 までの確認環境は、READMEの「動作確認した環境」を参照してください。

## 実機で未確認の項目
- Google ドライブでの書き出しと復元
- 変換エンジンの新しい画面と、「Mozcのみ」で AI の候補が出ないこと
- 追加システム辞書を「すべて」にしたときの変換速度への影響
- OpenRouter への接続
- 他の Android のバージョン、3ボタン / ジェスチャーナビ
- N100 などの x86_64 の Android(x86_64 版)での動作

## 配布する APK
配布する APK は **debug 署名のテスト用**で、アプリ ID は `jp.kanakana.ime.debug` です。正式な署名鍵は用意していません。1.0.0、1.0.1 と同じ署名なので、上書きで更新できます。

### ファイルの選び方
| ファイル | 対象 |
|---|---|
| `KanaKana-1.0.2-arm64-debug.apk` | 一般的なスマホ・タブレット(arm64)。AI 変換(Karukan・zenzai-plus)も使えます |
| `KanaKana-1.0.2-x86_64-debug.apk` | Intel / AMD の CPU で動く Android(N100 などのミニ PC、Android-x86 系、エミュレータ)。**AI 変換は使えません**(Mozc の変換のみ)。この組み合わせでの動作は、未確認です |
